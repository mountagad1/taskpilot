8. Article text

Tests read_page, summarize, translate, ask_ai.

Browser automation has historically meant brittle scripts: a selector recorded on Tuesday breaks on Wednesday because a framework re-rendered the DOM. The usual response is to record more selectors, which multiplies the maintenance rather than reducing it.

A more durable approach separates intent from mechanism. The intent — “capture the contact on this page and push it to the CRM” — is stable across redesigns. The mechanism — which element to click — is not, and should be resolved at execution time against whatever the page currently is, with fallbacks when the first strategy misses.

That separation also changes where cost lands. Most requests fall into a small number of recognisable shapes, and those need no model call at all. Reserving inference for genuine ambiguity keeps the median request free and fast, and makes the expensive path the exception rather than the rule.
